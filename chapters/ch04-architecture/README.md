# Chapter 4: Processor Architecture

Use the official Architecture Lab as the main implementation task for this
chapter. The handout includes the Y86-64 simulator source and the files that are
meant to be edited.

Suggested flow:

1. Read the Y86-64 instruction set summary.
2. Build and run the simulator from the handout without changes.
3. Modify only the files requested by the lab.
4. Keep a short note explaining each pipeline change.
