# Chapter Starters

This directory contains thin implementation starters by chapter. They are not
solutions; they are prompts for experiments before or alongside the official
labs.

| Chapter | Starter | Main lab |
| --- | --- | --- |
| 1. Tour | `ch01-tour/hello.c` | none |
| 2. Data | `ch02-data/bits.c` | Data Lab |
| 3. Machine code | `ch03-machine/inspect.c` | Bomb Lab, Attack Lab |
| 4. Processor architecture | `ch04-architecture/README.md` | Architecture Lab |
| 5. Optimization | `ch05-optimization/benchmark.c` | Performance Lab |
| 6. Memory hierarchy | `ch06-memory/cache_probe.c` | Cache Lab |
| 7. Linking | `ch07-linking/` | none |
| 8. Exceptional control flow | `ch08-control/process.c` | Shell Lab |
| 9. Virtual memory | `ch09-virtual-memory/allocator_notes.c` | Malloc Lab |
| 10. System I/O | `ch10-io/copy.c` | Proxy Lab preparation |
| 11. Network programming | `ch11-network/echo.c` | Proxy Lab |
| 12. Concurrency | `ch12-concurrency/counter.c` | Proxy Lab |

Build individual starters with `cc`, or use the local Makefile if a chapter has
one. Keep experiments small and replace them with official lab work when ready.
