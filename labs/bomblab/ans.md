## gdb 명령어
ni: next instruction, 다음 명령어 
si: call site에서 진입
x/i: 해당 지점에서 메모리를 검사(examine)하는데, instruction level에서.
x/10i: 10개를 보기. 
break "func": 특정 지점에 브레이크 걸기
continue: 다음 break 지점으로 이동
run: 처음부터 재실행
x/s: string으로 메모리지점 보기
i b(info breakpoints): breakpoints 모두 보기
i r(info registers): 모든 레지스터에 존재하는 값 보기
tbreak *메모리주소 / continue: 해당 메모리 주소로 이동
disable breakpointnumber: 해당 break point 꺼두기
delete breakpointnumber: 해당 break point 삭제
